# CineSphere

CineSphere is a movie and event ticket booking platform that will evolve from a modular monolith into a microservices-based, cloud-native system.

## Current Version

V1 - Project Setup

## Tech Stack

- Java 21
- Spring Boot
- Maven
- Spring Web
- Spring Boot Actuator

## Current Features

- Initial Spring Boot application
- Health endpoint

## Running the Application

Run the application using:

```bash
./mvnw spring-boot:run
